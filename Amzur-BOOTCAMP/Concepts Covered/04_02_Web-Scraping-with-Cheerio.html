What is Web Scraping?

The Process

Web scraping is the automated extraction of data from websites. Instead of manually copying content, you write code that:

  • Fetches HTML from a URL
  • Parses the HTML structure
  • Selects specific elements
  • Extracts desired data
  • Cleans and structures the content

Why Cheerio?

Cheerio is a fast, flexible HTML parsing library for Node.js that implements jQuery's core selector and manipulation functionality:

  • Familiar jQuery-like syntax
  • Fast and lightweight
  • Server-side parsing
  • No browser required
  • Perfect for static HTML

Project Requirements

For the Web Content Analyzer project, you must:

  • Extract title and meta description
  • Get all heading levels (h1-h6)
  • Capture main content text
  • Collect internal/external links
  • Filter navigation, ads, footer
  • Handle different site structures

The Scraping Pipeline

Your complete scraping workflow:

  • Step 1: Fetch HTML with Axios
  • Step 2: Load into Cheerio
  • Step 3: Select elements
  • Step 4: Extract data
  • Step 5: Clean and structure
  • Step 6: Send to LLM for analysis

HTML Structure Basics

Understanding the DOM

The Document Object Model (DOM) is a tree-like representation of an HTML document. Every HTML element is a node in this tree, with parent-child relationships.

Typical Blog Post HTML Structure:

<html>
<head>
<title> Understanding Web Scraping
<meta name="description"> A comprehensive guide...
<body>
<nav class="navigation"> 🚫 Skip this (navigation)
<main>
<article>
<h1> ✅ Extract this (main heading)
<p class="content"> ✅ Extract this (paragraph text)
<h2> ✅ Extract this (subheading)
<aside class="sidebar"> 🚫 Skip this (sidebar)
<footer> 🚫 Skip this (footer)

HTML Elements

Key components of HTML:

  • Tags: <div>, <p>, <h1>
  • Attributes: class="content", id="main"
  • Text Content: The actual text inside tags
  • Nesting: Elements inside other elements

Common Content Elements

Elements you'll typically extract:

  • <h1>-<h6>: Headings (hierarchy)
  • <p>: Paragraphs (main content)
  • <a>: Links (href attribute)
  • <ul>/<ol>: Lists
  • <article>: Main content container

CSS Selectors Reference

What are CSS Selectors?

CSS selectors are patterns used to select HTML elements. In Cheerio, they work exactly like jQuery selectors, allowing you to target specific elements for data extraction.

Element Selector

$('p')

Selects all <p> (paragraph) elements on the page.

$('h1')

Selects all <h1> (heading 1) elements.

Class Selector

$('.content')

Selects all elements with class="content".

$('.article-body')

Selects elements with class="article-body".

ID Selector

$('#main')

Selects the element with id="main" (should be unique).

$('#article-content')

Selects element with id="article-content".

Descendant Selector

$('article p')

Selects all <p> elements inside <article> elements.

$('main .content')

Selects .content elements inside <main>.

Direct Child Selector

$('article > p')

Selects <p> elements that are direct children of <article>.

$('div > .item')

Selects .item that are direct children of <div>.

Attribute Selector

$('a[href]')

Selects all <a> tags that have an href attribute.

$('[data-type="article"]')

Selects elements with data-type="article".

Multiple Selectors

$('h1, h2, h3')

Selects all <h1>, <h2>, and <h3> elements.

$('.title, .heading')

Selects elements with either class.

Not Selector

$('p:not(.ad)')

Selects <p> elements that don't have class="ad".

$('div:not(.sidebar)')

Excludes elements with .sidebar class.

First/Last Child

$('p:first-child')

Selects <p> elements that are the first child of their parent.

$('li:last-child')

Selects the last <li> in each list.

Nth Child

$('p:nth-child(2)')

Selects the second <p> element in its parent.

$('div:nth-child(odd)')

Selects odd-numbered <div> elements.

Contains Text

$('p:contains("keyword")')

Selects <p> elements containing specific text.

$('h2:contains("Chapter")')

Finds headings with "Chapter" in them.

Attribute Value

$('a[href^="https"]')

Selects links starting with "https" (external links).

$('img[src$=".jpg"]')

Selects images ending with .jpg.

Cheerio API Fundamentals

1. Loading HTML into Cheerio

▼

First, you need to load HTML into Cheerio. This is typically done after fetching HTML from a URL using Axios or another HTTP client.

Loading HTML

const axios = require('axios'); const cheerio = require('cheerio'); // Step 1: Fetch HTML from URL const response = await axios.get('https://example.com'); const html = response.data; // Step 2: Load HTML into Cheerio const $ = cheerio.load(html); // Now $ is your Cheerio instance (like jQuery) // You can use it to select and extract data
💡 The $ Variable

By convention, we name the Cheerio instance "$" because it works just like jQuery's $ selector. This makes the syntax familiar and easy to read.

2. Selecting Elements

▼

Use CSS selectors to find elements. Cheerio returns a collection that you can iterate over or manipulate.

// Select single element const title = $('h1').text(); // Select all paragraphs const paragraphs = $('p'); // Select by class const content = $('.article-content'); // Select by ID const main = $('#main-article'); // Complex selector const articleParagraphs = $('article.post p:not(.ad)'); // Check if element exists if ($('h1').length > 0) { console.log('H1 found!'); }

3. Extracting Data

▼

Once you've selected elements, extract text, attributes, or HTML content using Cheerio's methods.

// Extract text content const heading = $('h1').text(); // Result: "Welcome to My Blog" // Extract attribute value const link = $('a').attr('href'); // Result: "https://example.com/page" // Extract HTML content const htmlContent = $('.content').html(); // Result: "<p>Some text</p><p>More text</p>" // Extract multiple elements const allHeadings = []; $('h2').each((i, elem) => { allHeadings.push($(elem).text()); }); // Extract all links const links = []; $('a').each((i, elem) => { links.push({ text: $(elem).text(), href: $(elem).attr('href') }); });

4. Traversing the DOM

▼

Navigate between elements using parent, children, siblings, and other traversal methods.

// Find children const children = $('.container').children(); const paragraphs = $('.content').children('p'); // Find parent const parent = $('.item').parent(); // Find all descendants (not just direct children) const allLinks = $('article').find('a'); // Find next sibling const nextElement = $('h2').next(); // Find all siblings const siblings = $('.item').siblings(); // Closest ancestor matching selector const article = $('p').closest('article'); // Filter results const externalLinks = $('a').filter((i, el) => { return $(el).attr('href').startsWith('http'); });

5. Filtering & Removing Elements

▼

Remove unwanted elements (navigation, ads, scripts) before extracting content.

// Remove elements before extraction $('nav').remove(); // Remove navigation $('footer').remove(); // Remove footer $('.sidebar').remove(); // Remove sidebar $('script').remove(); // Remove scripts $('style').remove(); // Remove styles // Remove multiple elements at once $('nav, footer, .ad, .sidebar').remove(); // Remove by class pattern $('[class*="ad"]').remove(); // Removes class="ad", "ad-banner", "sidebar-ad" $('[id*="ad"]').remove(); // Removes id="ad-container", etc. // Now extract clean content const cleanContent = $('article').text();
⚠️ Remove Before Extracting

Always remove unwanted elements BEFORE extracting text. Once you call .text() or .html(), the structure is flattened and you can't easily remove navigation or ads from the result.

Content Extraction Patterns

Project Requirements

For your Web Content Analyzer, you must extract: title, meta description, all headings (h1-h6), main content text, paragraph count, word count, and links (internal/external).

Extract Title & Meta Description

▼
function extractMetadata($) { // Page title const title = $('title').text().trim(); // Meta description const description = $('meta[name="description"]').attr('content') || ''; // Meta keywords const keywords = $('meta[name="keywords"]').attr('content') || ''; // Open Graph title (social media) const ogTitle = $('meta[property="og:title"]').attr('content') || ''; // Author const author = $('meta[name="author"]').attr('content') || ''; return { title, description, keywords: keywords.split(',').map(k => k.trim()), ogTitle, author }; }

Extract All Headings (h1-h6)

▼
function extractHeadings($) { const headings = { h1: [], h2: [], h3: [], h4: [], h5: [], h6: [] }; // Extract each heading level ['h1', 'h2', 'h3', 'h4', 'h5', 'h6'].forEach(tag => { $(tag).each((i, elem) => { const text = $(elem).text().trim(); if (text) { headings[tag].push(text); } }); }); return headings; } // Example output: // { // h1: ["Main Article Title"], // h2: ["Introduction", "Key Concepts", "Conclusion"], // h3: ["What is Web Scraping?", "Why Use Cheerio?"], // h4: [], // h5: [], // h6: [] // }

Extract Main Content Text

▼
function extractMainContent($) { // First, remove noise elements $('nav, header, footer, aside, .sidebar, .menu, .ad, .advertisement, script, style, noscript').remove(); // Try to find main content container (in order of preference) let content = ''; // 1. Try <main> tag if ($('main').length > 0) { content = $('main').text(); } // 2. Try <article> tag else if ($('article').length > 0) { content = $('article').text(); } // 3. Try common content classes else if ($('.content, .post-content, .article-content, .entry-content').length > 0) { content = $('.content, .post-content, .article-content, .entry-content').first().text(); } // 4. Fallback to body (less ideal) else { content = $('body').text(); } // Clean the text content = content .replace(/\s+/g, ' ') // Replace multiple spaces with single space .replace(/\n+/g, ' ') // Replace newlines with space .trim(); // Remove leading/trailing whitespace return content; }

Extract Paragraphs & Count Words

▼
function extractParagraphsAndStats($) { // Remove noise first $('nav, footer, aside, .ad').remove(); const paragraphs = []; let totalWords = 0; // Extract paragraphs from main content areas $('article p, main p, .content p').each((i, elem) => { const text = $(elem).text().trim(); // Skip very short paragraphs (likely not real content) if (text.length > 20) { paragraphs.push(text); // Count words in this paragraph const words = text.split(/\s+/).filter(w => w.length > 0); totalWords += words.length; } }); return { paragraphs, paragraphCount: paragraphs.length, wordCount: totalWords, avgWordsPerParagraph: paragraphs.length > 0 ? Math.round(totalWords / paragraphs.length) : 0 }; }

Extract Links (Internal vs External)

▼
function extractLinks($, baseUrl) { const links = { internal: [], external: [], all: [] }; // Parse base URL to compare domains const urlObj = new URL(baseUrl); const baseDomain = urlObj.hostname; $('a[href]').each((i, elem) => { const href = $(elem).attr('href'); const text = $(elem).text().trim(); // Skip empty or anchor links if (!href || href.startsWith('#') || href.startsWith('javascript:')) { return; } const linkData = { href, text }; // Determine if internal or external if (href.startsWith('http') || href.startsWith('https')) { // Full URL - check domain try { const linkUrl = new URL(href); if (linkUrl.hostname === baseDomain) { links.internal.push(linkData); } else { links.external.push(linkData); } } catch (e) { // Invalid URL, skip } } else { // Relative URL - it's internal links.internal.push(linkData); } links.all.push(linkData); }); return { internal: links.internal, external: links.external, internalCount: links.internal.length, externalCount: links.external.length, totalCount: links.all.length }; }

Filtering Noise & Cleaning Content

Critical for Project Success

Your Web Content Analyzer must extract only meaningful content. Navigation menus, advertisements, footers, and sidebars should be excluded. This is worth significant points in your evaluation rubric.

❌ Without Filtering (Bad)

function extractContent($) { // BAD: Just grabs everything from body const content = $('body').text(); return content; } // Result includes: // "Home About Contact Login... [actual article]... // BUY NOW! Advertisement... Subscribe to Newsletter // Copyright 2024... Privacy Policy Terms" // Problems: // ❌ Navigation menu text included // ❌ Advertisement text included // ❌ Footer copyright included // ❌ Sidebar widgets included // ❌ Low-quality LLM analysis result

✅ With Proper Filtering (Good)

function extractCleanContent($) { // STEP 1: Remove noise elements $('nav').remove(); $('header').remove(); $('footer').remove(); $('aside').remove(); // STEP 2: Remove by class/id patterns $('.sidebar, .menu, .navigation').remove(); $('.ad, .advertisement, .banner').remove(); $('.social-share, .comments').remove(); $('[class*="ad-"]').remove(); $('[id*="ad"]').remove(); // STEP 3: Remove scripts and styles $('script, style, noscript').remove(); // STEP 4: Now extract from main content let content = $('main').text() || $('article').text() || $('.content').text(); // STEP 5: Clean whitespace content = content .replace(/\s+/g, ' ') .trim(); return content; }
✅ Complete Filtering Checklist

Always Remove These Elements:

  • ✓ Navigation: <nav>, .navigation, .menu, #menu
  • ✓ Header: <header>, .header, .site-header
  • ✓ Footer: <footer>, .footer, .site-footer
  • ✓ Sidebar: <aside>, .sidebar, .widget
  • ✓ Ads: .ad, .advertisement, [class*="ad-"], .banner
  • ✓ Social: .social-share, .share-buttons
  • ✓ Comments: .comments, #comments
  • ✓ Code: <script>, <style>, <noscript>

Common Pitfalls & Solutions

❌ Pitfall 1: Not Checking if Element Exists

Trying to extract from elements that don't exist causes errors or returns undefined.

✅ Solution:

Always check .length before extracting or use optional chaining:

// BAD const title = $('h1').text(); // Might be empty // GOOD const title = $('h1').length > 0 ? $('h1').text() : 'No title found';

❌ Pitfall 2: Using Too Specific Selectors

Selectors that only work for one specific website will break on others.

✅ Solution:

Use flexible, semantic selectors that work across different sites:

// BAD - Too specific const content = $('.post-body-container-inner-wrapper').text(); // GOOD - More flexible const content = $('main').text() || $('article').text() || $('.content, .post-content').first().text();

❌ Pitfall 3: Not Trimming or Cleaning Text

Extracted text often has excessive whitespace, newlines, and special characters.

✅ Solution:

Always clean extracted text:

// BAD const text = $('p').text(); // Result: " Some text\n\n with weird spacing " // GOOD const text = $('p').text() .replace(/\s+/g, ' ') // Normalize whitespace .trim(); // Remove leading/trailing // Result: "Some text with weird spacing"

❌ Pitfall 4: Forgetting to Remove Noise First

Extracting text before removing navigation, ads, and footer includes unwanted content.

✅ Solution:

Always remove noise elements BEFORE extracting text:

// BAD - Extract first const content = $('body').text(); $('nav').remove(); // Too late! // GOOD - Remove first $('nav, footer, .ad').remove(); // Remove FIRST const content = $('body').text(); // Then extract

❌ Pitfall 5: Not Handling Empty Results

When selectors don't match anything, operations fail or return empty strings.

✅ Solution:

Provide fallback values and validation:

function extractWithFallback($) { // Try multiple selectors with fallback const content = $('article').text() || $('main').text() || $('.content').text() || 'No content found'; // Validate minimum length if (content.length < 100) { throw new Error('Insufficient content extracted'); } return content; }

❌ Pitfall 6: Not Handling Different HTML Structures

Each website has a different HTML structure. Your scraper must be adaptable.

✅ Solution:

Use multiple fallback strategies:

function intelligentContentExtraction($) { // Try semantic HTML5 tags first if ($('main').length > 0) return $('main').text(); if ($('article').length > 0) return $('article').text(); // Try common class names const commonClasses = ['.content', '.post-content', '.article-content', '.entry-content']; for (const selector of commonClasses) { if ($(selector).length > 0) { return $(selector).first().text(); } } // Last resort: body (after removing noise) $('nav, footer, aside').remove(); return $('body').text(); }

Tools & Setup

Essential Libraries for Web Scraping

📦 Cheerio

Fast, flexible HTML parsing library with jQuery-like syntax. Core library for your Web Content Analyzer project.

npm install cheerio

Use for: Parsing HTML, selecting elements, extracting content

🌐 Axios

Promise-based HTTP client for fetching HTML from URLs. Reliable and easy to use with good error handling.

npm install axios

Use for: Fetching HTML from websites, making HTTP requests

🎭 Puppeteer (Optional)

Headless Chrome browser for JavaScript-heavy websites. Use when Cheerio can't handle dynamic content (stretch goal).

npm install puppeteer

Use for: Scraping JavaScript-rendered content, SPAs

🧹 html-entities

Decode HTML entities (&amp; → &, &lt; → <). Essential for cleaning scraped text.

npm install html-entities

Use for: Decoding HTML entities in extracted text

✅ Validator

String validation and sanitization library. Use for validating URLs and sanitizing input.

npm install validator

Use for: URL validation, input sanitization

📝 Express-Validator

Express middleware for request validation. Validate incoming URLs and request parameters.

npm install express-validator

Use for: API endpoint validation, request sanitization
